## 🔧 Customization Tips

### Changing Colors
Edit the CSS variables in `sesame-exchange.css`:
```css
:root {
    --primary-purple: #8B5CF6;
    /* Change to your preferred colors */
}
```

### Adding More Features
Copy the feature-item structure in the HTML and add your content:
```html
<div class="feature-item">
    <div class="feature-content">
        <!-- Your content -->
    </div>
    <div class="feature-visual">
        <!-- Your screenshot -->
    </div>
</div>
```

### Code Snippets
The Prism.js library handles syntax highlighting. Just wrap your code:
```html
<pre><code class="language-dart">
// Your Dart code here
</code></pre>
```
